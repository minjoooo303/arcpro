# Arctic Ship Dashboard

북극 항로 선박 운항을 위한 실시간 대시보드

## 기능

- **상단**: 경로/지도 패널 - 항로 + 장애물 표시
- **중단**: 운항 계기판 클러스터 - Navigation, Engine, Fuel, Environment 카드
- **하단**: 모드 전환 + 상세 위젯 - 7가지 대시보드 모드
- **좌측**: 선박 단면도 + 클릭 핫스팟 - 부위별 상세 정보

## 설치

```bash
npm install
```

## 실행

```bash
npm run dev
```

## 빌드

```bash
npm run build
```

## 기술 스택

- React 18
- Arwes (Sci-Fi UI Framework)
- Recharts (데이터 시각화)
- Lucide React (아이콘)
- Vite (빌드 도구)
